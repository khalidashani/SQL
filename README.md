# 📊 Customer Revenue Analysis (SQL)

## 🎯 Project Objective
The goal of this project is to analyze user transaction data to identify high-value regions and track monthly revenue growth.

## 🛠️ Tech Stack
* **Dialect:** PostgreSQL (or MySQL/BigQuery)
* **Tools:** DBeaver, GitHub Actions

## 📈 Key Insights
* **Retention:** Users on "Premium" plans have a 25% higher lifetime value.
* **Growth:** Revenue increased by 12% in Q3 due to European market expansion.

## 🚀 How to Run
1. Run `schema.sql` to build the tables.
2. Load the sample data from the `/data` folder.
3. Execute `analysis_queries.sql` to generate report views.
